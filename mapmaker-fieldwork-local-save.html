Known limits of this concept build
  • Pie charts can't be represented in the local format, so that style saves as plain base-colour points. Every other style — locations, by type, by size, by colour & size, by type & size — carries over faithfully.
  • Labels are written as separate on-map text at each point; the local POC lifts them just off the marker with a fixed offset, so the gap stays constant at every zoom.
  • The CSV is still parsed by ArcGIS Online's anonymous analyze/generate, and the preview basemap loads online — so this build is “no account”, not yet fully offline. Replacing that parse step with a client-side parser is what would make it work disconnected.
